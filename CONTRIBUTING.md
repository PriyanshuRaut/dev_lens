# How to Contribute

Thanks for your interest in improving this project.

## Getting started

1. Fork the repository and clone your fork.
2. Create a topic branch from the default branch.
3. Install dependencies and run the test suite:

Follow the build steps in the README.

## Development guidelines

- Keep pull requests focused on a single change.
- Match existing code style and naming.
- Add or update tests when you change behavior.
- Update docs when you change user-facing behavior.

## Pull request checklist

- [ ] Code builds locally
- [ ] Tests pass
- [ ] Commit messages are clear
- [ ] Related issue is linked (e.g. `Fixes #123`)

## Code of conduct

Be respectful and constructive in reviews and discussions.
